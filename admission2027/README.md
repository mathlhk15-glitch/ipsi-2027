# 2027 대입 전략 가이드 웹앱

학생·학부모가 「2026 대입 분석과 2027 지원 전략 가이드」 216쪽을 전형별로 탐색하고, 검색·필터·고화질 확대할 수 있도록 재구성한 정적 웹앱입니다.

## 배포 주소

기본 배포 경로는 다음으로 설정했습니다.

`https://mathlhk15-glitch.github.io/ipsi-2027/admission2027/`

다른 경로에 배포할 경우 `index.html`의 `og:url`, `og:image` 두 주소만 실제 경로로 변경하세요.

## 배포 방법

1. 이 `site` 폴더의 **내용 전체**를 GitHub 저장소의 `admission2027/` 폴더에 업로드합니다.
2. GitHub Pages가 `main` 브랜치의 루트 또는 `/docs`에서 배포되도록 설정합니다.
3. 위 배포 주소에서 `index.html`이 열리는지 확인합니다.
4. 카카오톡 등에서 공유하기 전에 OG 미리보기 캐시를 갱신하거나 새 URL로 테스트합니다.

## 주요 기능

- 원문 216쪽 전체 수록
- 썸네일 216장 + 200dpi 고화질 이미지 216장
- 전형별 필터와 제목·본문 텍스트 검색
- 검색어 강조와 결과 문장 미리보기
- 키보드 접근 가능한 슬라이드 카드
- `#page-128` 형식의 페이지 딥링크
- 이전·다음 페이지, 링크 복사, 원문 PDF, 고화질 새 탭 보기
- 충원율 단순 환산과 과탐 백분위 단순 가산 예시
- 고1·고2·고3 학년별 확인 항목
- 1200×630 공유용 OG 이미지
- 표·차트·배치도 등 선형 텍스트로 구조가 완전히 보존되지 않는 페이지 자동 표시

- 이 웹앱은 **2026년 8월 제공된 연수 발표자료**를 바탕으로 합니다.
- 대학별 모집인원, 전형방법, 수능최저, 선택과목 제한, 가산점은 이후 변경될 수 있습니다.
- 실제 지원 전에는 해당 대학의 **2027학년도 최종 모집요강**을 반드시 확인해야 합니다.
- 자동 추출 텍스트는 검색 편의를 위한 참고 자료입니다. 표·차트·상담 배치도의 정확한 수치와 항목 대응은 원문 이미지로 확인하세요.
- 계산 도구는 대학별 공식 환산점 계산기가 아니라 자료 이해를 위한 단순 예시입니다.

## 이번 통합 개선 사항

클로드가 제공한 실제 배포 경로 수정본과 데이터 교정본을 기반으로, 학생·학부모의 모바일 사용성을 추가 보완했습니다.

- 70%컷·충원율·환산점수 등 **입시 용어 사전**
- 자주 찾는 검색어 바로가기
- 페이지 별표 저장, 저장 목록, 최근 본 페이지

- 모바일 기본 큰 카드 1열과 큰 카드/작은 카드 전환
- 고화질 이미지 로딩 상태 표시
- 확대·축소·원래 크기 버튼
